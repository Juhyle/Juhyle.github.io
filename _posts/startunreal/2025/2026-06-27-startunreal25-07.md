## 목표 : 언리얼 엔진에서 컨피규레이터가 동작하는 장면을 연출

저번 시간에, 캐릭터가 토스터 가까이 가면 카메라가 전환이 되고, H를 누르면 특정 시퀀스가 작동되도록 블루프린트를 만들어줬다.
하지만 여기에는 문제점이 있다. 바로 컨피규레이터가 작동하는 동안에 캐릭터가 움직일 수 있다는 점이다. 오늘은 시작은 캐릭터 접근으로 하되, 버튼을 통해 종료할 수 있도록 만들어보자.

## [Troubleshooting]


### 1. 메타휴먼의 팔 각도 보정

* **원인 분석** : 이전 프로젝트에서 성인 마네킹을 기준으로 제작된 애니메이션을 어린아이 체형의 메타휴먼에 적용하면서 팔의 각도가 자연스럽지 않게 꺾이는 문제가 발생했습니다.

* **해결 방안** : 과제 피드백을 반영하여 메타휴먼의 손목과 팔이 보다 자연스럽게 보이도록 팔목의 `소스에 블렌드 값을 조정`하여 자세를 보정했습니다.

### 2. 컨피규레이터 실행 중 캐릭터가 이동하는 문제

* **문제 상황** : 캐릭터가 토스터에 접근하면 카메라가 컨피규레이터 화면으로 전환되고, H 키 입력을 통해 특정 시퀀스가 실행되도록 구현했습니다. 하지만 컨피규레이터가 실행되는 동안에도 캐릭터의 이동이 가능하여, 조작 과정에서 캐릭터가 상호작용 범위를 벗어나 컨피규레이터가 종료되는 문제가 발생했습니다. 또한 컨피규레이터 실행 중에는 마우스 커서가 표시되지 않아 UI 버튼을 직접 조작할 수 없었습니다.

* **원인 분석** : 컨피규레이터 실행 여부와 관계없이 기존 캐릭터의 이동 입력이 계속 활성화되어 있었으며, 카메라 전환 시 Player Controller의 마우스 커서 표시 상태도 변경하지 않았기 때문에 UI 조작이 어려운 상태였습니다.

* **해결 방안** : 컨피규레이터가 실행되면 `Set Movement Mode`를 `None`으로 설정하여 캐릭터의 이동을 제한하고, `Set Show Mouse Cursor`를 활성화하여 마우스 커서를 표시하도록 블루프린트를 구성했습니다. 컨피규레이터가 종료되면 `Set Movement Mode`를 `Walking`으로 변경하여 캐릭터의 이동을 다시 활성화하고, 마우스 커서를 숨기도록 설정했습니다.

이를 통해 컨피규레이터 실행 중 캐릭터가 상호작용 범위를 벗어나는 것을 방지하고, 마우스를 이용해 UI 버튼을 조작할 수 있도록 개선했습니다.

### 3. 머티리얼 적용 과정에서 발생한 문제

* **문제 상황** : Nintendo Switch 화면에 외부 이미지를 머티리얼로 적용하는 과정에서 이미지의 방향과 크기, 색상이 의도와 다르게 표현되는 문제가 발생했습니다.

* **원인 분석 및 해결 과정** : 이미지를 적용했을 때 화면에서 이미지가 거꾸로 표시되는 문제를 확인하여, 원본 이미지를 180도 회전한 후 적용했습니다. 그리고 이미지 전체가 표시되지 않고 일부 영역이 확대되어 나타나는 문제가 발생했습니다. UV 좌표 설정을 추가로 조정하는 방법을 시도했으나 원하는 결과를 얻지 못해, `U Tiling`과 `V Tiling` 값을 조절하여 이미지가 최대한 의도한 형태로 표시되도록 수정했습니다.머티리얼 적용 후 이미지의 채도가 원본과 다르게 표현되는 문제도 발생했으나, 해당 문제의 정확한 원인은 해결하지 못했습니다.

<p align="center">
  <img src="/assets/images/2026-06-27/SU25-07-02.png" style="width:700px;">
</p>

* **추후 개선** : 이미지의 색상과 UV 좌표가 의도와 다르게 적용되는 원인을 추가로 학습하여, 이후 프로젝트에서 동일한 문제가 발생하지 않도록 보완할 예정입니다.
